# AGENTS.md

Instructions for AI coding agents (Copilot, Codex, Claude, Gemini, Oh My Pi
and others) working in this repository. Humans: see
[CONTRIBUTING.md](CONTRIBUTING.md) and [docs/](docs/).

This file is the single source of truth for agents.
`.github/copilot-instructions.md` is a short summary for Copilot features that
do not read this file (for example code review): keep the two consistent when
you change rules here.

## What this project is

`omp-usage` records LLM token usage and reported cost from
[Oh My Pi (OMP)](https://github.com/can1357/oh-my-pi) and exposes it to
Prometheus and Grafana.

```
OMP ──(plugin, message_end)──> JSONL files ──(exporter)──> SQLite ──> /metrics ──> Prometheus ──> Grafana
```

The plugin only writes files. The exporter imports, stores, aggregates and
serves HTTP. There is no network communication from the plugin.

## Commands

Node 22 (`.nvmrc`); Node 22 and 24 are tested on Linux and macOS.

```bash
npm ci
npm run build              # protocol -> plugin -> exporter
npm run check              # format:check + lint + typecheck + unit + integration (run before every PR)
npm test                   # unit tests (Vitest), all workspaces
npm run test:integration   # real exporter processes, signals, SQLite, plugin -> exporter e2e
npm run format             # Prettier
npm run docs:build         # mkdocs build --strict (needs pip install -r docs/requirements.txt)
```

Dashboards and Prometheus rules:

```bash
python3 examples/grafana/generate.py           # regenerate dashboards after editing generate.py
python3 examples/grafana/generate.py --check   # CI fails if the JSON is out of date
promtool check rules examples/prometheus/rules/*.yml
promtool test rules examples/prometheus/tests/*.yml
PROMETHEUS_DIR=... examples/grafana/validate/run.sh   # every panel query must return data (Docker or GRAFANA_HOME)
```

Pricing schema: `UPDATE_SCHEMA=1 npx vitest run src/pricing-schema.test.ts` in
the exporter regenerates `examples/pricing/pricing.schema.json`.

## Rules that must not be broken

Accounting and data:

- Never invent OMP event names. Verify them in the OMP
  [extension docs](https://github.com/can1357/oh-my-pi/blob/main/docs/extensions.md).
  The plugin uses `message_end` and `session_shutdown` (2 s budget). There is
  no `shutdown` event.
- Never guess the underlying model of a router alias: `openrouter/free` stays
  `openrouter/free`, with price 0.
- `:free` OpenRouter models may be priced at their paid variant (provider
  `openrouter` only). Never apply one model's price to another model.
- Keep **reported cost** (`omp_llm_reported_cost_usd_total`, from OMP) separate
  from **equivalent cost** (tokens × price, computed at query time). Never write
  prices into the reported cost.
- Missing usage is not zero (`omp_llm_usage_missing_total`). A direction
  without a price is not priced at zero.
- Reasoning tokens are a detail of output: do not add them to output again.
  Do not add `totalTokens` to the per-direction counters.
- Never add OMP metrics to llama.cpp metrics (`llamacpp:*`, job `llm`): the
  same local generation can appear in both. Ratios and side-by-side panels only.
- Never use event id, session id, timestamps, prompts or file paths as
  Prometheus labels. Label cardinality is capped (`--max-label-cardinality`);
  overflow goes to `_other`, events are never dropped from the database.
- The plugin records usage metadata only: no prompt, response, tool input or
  output, API keys or headers.

Exporter behaviour:

- Import, aggregate update and cursor advance happen in one SQLite
  transaction; `eventId` is UNIQUE; restarts must never double count.
- One exporter per database (side lock file). Read only complete lines; keep
  partial lines; bound line length.
- Default listen address is `127.0.0.1:9464`. LAN binding is explicit.
- Files are opened once and checked with `fstat` on the same descriptor (no
  check-then-read races; CodeQL `js/file-system-race`).

Repository:

- No private IP addresses in code or defaults. The user's addresses
  (`192.168.188.50` exporter and llama.cpp, `192.168.188.170` Prometheus and
  Grafana) may appear only in example configs.
- The protocol workspace must not be imported at runtime by a published
  package (the package smoke test checks the emitted JavaScript).
- Pin GitHub Actions by full commit SHA with a version comment. Keep
  `permissions` minimal per workflow and `persist-credentials: false`.
- Code, comments, docs and commit messages are in English.

## Pull requests and releases

- `main` is protected: PRs only, squash merge only, linear history, required
  checks, conversations resolved.
- PR titles are Conventional Commits (`pr-title.yml`), types `feat fix perf
refactor docs test build ci chore style revert`, optional scopes `plugin
exporter protocol docs ci deps deps-dev grafana main`.
- **The squash commit is what release-please reads.** Use `!` or a
  `BREAKING CHANGE:` footer only for real breaking changes of the packages the
  PR touches. When squashing, replace the prefilled commit list with a short
  description: footers from intermediate commits would otherwise be released
  again.
- Do not stack PRs on each other's branches. Base every PR on `main`: stacked
  PRs merged into their base branch never reach `main`.
- release-please opens one release PR per package
  (`separate-pull-requests`). Merging it tags the release and dispatches
  `publish.yml`, which publishes to npm with OIDC Trusted Publishing
  (environment `npm`, provenance). There is no npm token.
- Never publish, push tags or change repository, npm or ruleset settings
  unless the maintainer asks explicitly.
- Add or update tests with every behaviour change (unit, and integration when
  processes, files or signals are involved). Update `docs/` in the same PR.
- Dashboards: edit `examples/grafana/generate.py`, never the JSON by hand.

Open points:

- Verified only with the OpenRouter provider on OMP 18.8.6; other providers
  (for example GitHub Copilot) and subagent coverage are not verified yet.
- `increase()` attributes usage to the scrape that saw it, not to the event
  time; history imported later lands at import time (documented limitation).
- Prices are current values applied to the whole range (no price history).
